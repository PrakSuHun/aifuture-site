# 한국AI미래연구회

KOREA AI FUTURE RESEARCH SOCIETY 공식 웹사이트.

## 구조

- `index.html` — 사이트 본체
- `content.json` — 모든 텍스트와 이미지 경로
- `admin/` — 관리자 페이지 (Sveltia CMS)
- `uploads/` — CMS가 업로드한 사진 보관
- `assets/` — 디자인 템플릿 자산 (CSS/JS/이미지)

## 관리자 페이지

배포 후 `사이트URL/admin/` 으로 접속 → GitHub 로그인 → 텍스트와 사진 직접 편집.

자세한 설정은 [SETUP.md](SETUP.md) 참조.
